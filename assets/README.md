# Assets

- `Inter-Bold-subset.ttf`: Inter Bold, subset to printable ASCII, from
  the solitaire project (its assets/README.md says how it was made from
  the upstream Inter variable font with fonttools). Embedded into the
  program with `#embed` in `src/font.cpp`.
- `Inter-LICENSE.txt`: Inter's license, the SIL Open Font License 1.1.
  Copyright The Inter Project Authors (https://github.com/rsms/inter).
- `euchre.ico`: the Windows icon, drawn by the program itself:

      $ ./build/euchre --icon assets/euchre.ico
